# Online Examination System

## 📌 Project Overview

The Online Examination System is a Java-based desktop application developed using Java Swing.

This application allows students to log in, update their profile, attend an online examination, answer multiple-choice questions, and view their examination results.

## 🚀 Features

- Student Login
- Student Profile Management
- Password Update
- Multiple Choice Questions (MCQs)
- Previous and Next Question Navigation
- 30-minute Examination Timer
- Automatic Submission when Time Ends
- Question Answer Tracking
- Automatic Score Calculation
- Correct, Incorrect and Unanswered Question Count
- Examination Result Display
- Logout Functionality

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming (OOP)
