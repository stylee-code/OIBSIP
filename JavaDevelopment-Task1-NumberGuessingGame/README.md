Number Guessing Game
Project Description

Number Guessing Game is a Java console-based game in which the computer generates a random number and the user tries to guess it.

The program gives hints such as "higher" or "lower" after each incorrect guess.

Features
Generates a random number
Number range from 1 to 100
User can enter guesses
Gives Higher or Lower hints
Maximum 10 attempts
Calculates the user's score
Shows the number of attempts taken
Displays the final result
Technology Used
Java
Visual Studio Code
How the Game Works
The computer generates a random number.
The user enters a guess.
The program compares the guess with the random number.
If the guess is lower, the program gives a lower-number hint.
If the guess is higher, the program gives a higher-number hint.
If the guess is correct, the user wins.
The program calculates and displays the score.
